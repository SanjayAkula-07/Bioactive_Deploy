Project Context

About BioPredict

Computational chemistry virtual screening for drug candidate prioritization.

Problem Statement

Identifying bioactive compounds for therapeutic targets like Cyclooxygenase-2 (COX-2) is a core step in early drug development. Traditional high-throughput screening is resource-intensive. Machine learning allows rapid virtual pre-screening to prioritize active candidates and eliminate inactive molecules.

Target & Threshold

Molecules are classified as Active if experimental inhibition meets
IC50 < 10,000 nM, and Inactive if IC50 ≥ 10,000 nM.

Methodology & Fingerprints

Chemical structures are normalized and mapped to 2048-bit Morgan Circular Fingerprints (radius = 2, ECFP4-equivalent) using RDKit. These topological representations encode atom neighborhoods and functional groups for the classifier.

Research & Educational Purpose: Predictions are computational estimates to guide laboratory exploration and do not constitute medical validation or clinical safety verification.
